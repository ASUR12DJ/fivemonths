FIVE MONTHS OF US — GITHUB PAGES FILES

Keep index.html in the top level of your GitHub repository.

ADD YOUR SONG
The page looks for the song at:
  assets/our-song.mp3

Put your MP3 in the assets folder and name it our-song.mp3 before uploading.
The song is not included in this package yet. You can also choose an audio file
from the page's music message to preview it on your own device.

PUBLISH ON GITHUB PAGES
1. Extract this ZIP on your computer.
2. Create a new public repository on GitHub.
3. Upload index.html, README.txt, and the assets folder to the repository's top level.
4. In the repository, open Settings, then Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and /(root), then save.
7. After GitHub finishes publishing, its Pages screen will show the link to send Kavya.

The page starts the song after a tap, because browsers block automatic audio playback.
